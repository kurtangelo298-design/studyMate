# StudyMate PH 🎓
**Plan · Study · Achieve** — Fully functional study companion app (Python + CustomTkinter)

## ✨ Features
- **Loading Screen** — animated graduation cap with colorful ring (green/blue/pink)
- **Login Form** — default: `kath` / `1234` (with show/hide password)
- **Home Dashboard** — Today's Schedule, Upcoming Deadlines, Quick Stats (donut chart), Quick Actions, motivational banner, bottom nav bar
- **My Tasks** — add/complete/delete tasks, filter (All/Pending/Completed/Overdue), auto-save
- **Calendar** — month view with events, add events per day
- **Study Space** — flashcards with flip, study tips
- **Group Projects** — project list with progress bars
- **Notes & Files** — full notes editor (create/edit/save/delete), auto-save to JSON
- **Grades** — grade table with auto GWA computation (Philippine scale), add/delete grades
- **Study Planner** — Pomodoro timer (25 min focus / 5 min break), start/pause/reset
- **Budget Tracker** — income/expense tracker with balance, transaction history
- **Settings** — edit profile name/course/password
- **More Features:** Deadline Reminder, Missed Task Recovery, Export Reports (CSV), Time Estimator, AI Study Assistant (keyword-based chat), Exam Countdown, Focus Mode (50-min deep work timer)

## 🚀 How to Run
```bash
pip install -r requirements.txt
python studymate_ph.py
```

## 🔑 Default Login
- Username: `kath`
- Password: `1234`

## 💾 Data
All changes (tasks, notes, grades, budget, exams, calendar events) are auto-saved to `studymate_data.json` next to the script. Delete that file to reset to default data.

## 🎨 Design
Dark theme matching the StudyMate PH mockup — purple/blue accents, rounded cards, gradient highlights.
